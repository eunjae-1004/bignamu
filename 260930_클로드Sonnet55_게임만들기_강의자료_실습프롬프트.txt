[Claude Sonnet 5.5 vs Opus 5.5 vs GPT-6-Sol]
강의자료 + 실습 템플릿 프롬프트

작성 목적
- 영상/강의 수강생 배포용
- AI 모델 비교 실습용
- 동일 프롬프트로 여러 AI 모델의 결과를 비교하기 위한 자료


==================================================
1. 강의자료
==================================================

■ 오늘의 핵심 질문

가장 비싼 AI가 항상 가장 좋은 AI일까요?

중요한 것은 단순히 가장 비싼 모델을 선택하는 것이 아니라,
내가 하려는 일을 적절한 비용으로 잘 끝내는 AI를 선택하는 것입니다.


■ 비교 모델

1) Claude Sonnet 5.5
2) Claude Opus 5.5
3) GPT-6-Sol


■ Sonnet 5.5에서 볼 핵심 포인트

1. 속도
- 이전 Sonnet 5보다 작업을 더 빠르게 끝낼 수 있음
- 같은 작업에서도 결과 생성 속도가 개선됨

2. 코딩 능력
- 단순히 코드 몇 줄을 생성하는 것을 넘어
  기능 구현, 오류 수정, 작업 완료까지 이어지는 능력을 비교

3. 비용 효율
- 단순 토큰 단가만 보는 것이 아니라
  하나의 작업을 완료하는 데 실제로 얼마나 많은 토큰과 비용이 필요한지 확인


■ 벤치마크를 볼 때 주의할 점

벤치마크 하나가 AI의 모든 능력을 의미하지 않습니다.

예를 들어,
- 명확한 코딩 작업
- 문서 작성
- 기획
- 복잡한 판단
- 여러 자료를 종합하는 작업

은 서로 요구하는 능력이 다릅니다.

따라서 모델을 비교할 때는
벤치마크 점수뿐 아니라 실제 결과물을 함께 확인해야 합니다.


■ Sonnet과 Opus의 활용 관점

Sonnet 5.5가 잘 맞는 작업 예시
- "이 기능을 만들어줘"
- "이 오류를 고쳐줘"
- 명확한 코딩 작업
- 반복 업무
- 일반적인 문서 및 자료 제작

Opus 5.5가 잘 맞을 수 있는 작업 예시
- 문제 자체가 명확하지 않은 작업
- 많은 자료를 검토해야 하는 작업
- 중간에 여러 번 판단이 필요한 작업
- 복잡한 기획 및 추론 작업


■ 실제 AI 결과물을 평가하는 기준

AI가 만든 프로그램은 최소 두 가지를 확인해야 합니다.

1) 보기 좋은가?
2) 제대로 작동하는가?

시각적으로 예쁘다고 해서
기능적으로 잘 만들어진 프로그램이라는 뜻은 아닙니다.

예를 들어 다음을 확인해야 합니다.

- 캐릭터가 정상적으로 움직이는가?
- 충돌 판정이 작동하는가?
- 요청한 기능이 빠지지 않았는가?
- 목적지 도착 조건이 제대로 작동하는가?
- 화면 요소가 요청한 조건과 일치하는가?


■ 가격을 비교할 때 중요한 기준

단순히
"100만 토큰당 얼마인가?"
만 보면 충분하지 않습니다.

더 중요한 질문은 다음과 같습니다.

"내 일을 하나 끝내는 데 실제로 얼마가 들었는가?"

모델마다
- 한 번에 작업을 끝내는 정도
- 사용하는 토큰 수
- 캐시 사용
- 추론 수준

이 다를 수 있기 때문입니다.


■ 추론 수준은 높을수록 항상 좋은가?

항상 그렇지는 않습니다.

복잡하지 않은 작업에서 지나치게 높은 추론 수준을 사용하면
- 필요 이상으로 작업을 확대하거나
- 여러 번 검토하면서
- 더 많은 시간과 토큰을 사용할 수 있습니다.

따라서

간단한 작업
→ 적당한 추론 수준부터 시작

복잡한 작업
→ 필요할 때 높은 추론 수준 사용

과 같은 방식으로 접근할 수 있습니다.


■ 오늘의 핵심 정리

가장 비싼 AI가 항상 가장 좋은 선택은 아닙니다.

해야 할 일이 명확하다면
상대적으로 저렴한 모델도 충분히 좋은 결과를 만들 수 있습니다.

반대로
문제가 복잡하고 중간 판단이 많이 필요하다면
더 강한 모델이 필요할 수 있습니다.

앞으로는

"제일 좋은 AI가 무엇인가?"

보다

"내 일을 가장 적절한 비용으로 잘 끝내는 AI는 무엇인가?"

를 기준으로 모델을 선택해 보세요.

2. 실습 1
동일 프롬프트로 AI 모델 비교하기
==================================================

[실습 목표]

Claude Sonnet 5.5, Claude Opus 5.5, GPT-6-Sol 등
여러 AI 모델에 동일한 프롬프트를 입력한 뒤
결과물의 차이를 직접 비교합니다.


[실습 방법]

1. 아래 프롬프트를 복사합니다.
2. 비교하려는 AI 모델 각각에 동일하게 입력합니다.
3. 첫 번째 결과에서는 추가 수정 요청을 하지 않습니다.
4. 각 모델이 한 번의 요청으로 어디까지 구현하는지 확인합니다.
5. 결과물을 동일한 평가 기준으로 비교합니다.

3. 실습 템플릿 프롬프트
==================================================

[게임 제작 프롬프트]

서울 강남의 출근길을 배경으로 간단한 웹 게임을 만들어줘.

아래 조건을 모두 반영해줘.

[게임 구성]

- 사용자가 조작할 수 있는 캐릭터가 있어야 해.
- 캐릭터는 키보드 방향키 또는 WASD로 움직일 수 있게 해줘.
- 도로에는 자동차가 계속 움직이게 해줘.
- 보행자도 화면 안에서 움직이게 해줘.
- 횡단보도를 만들어줘.
- 신호등을 만들어줘.
- 편의점을 만들어줘.
- 카페를 만들어줘.
- 지하철 입구를 만들어줘.
- 건물과 상점에는 한국어 간판을 넣어줘.
- 전체적인 분위기는 서울 강남의 출근길처럼 표현해줘.

[게임 규칙]

- 캐릭터가 자동차와 충돌하면 처음 위치로 돌아가게 해줘.
- 캐릭터가 회사에 도착하면
  "출근 성공!" 메시지가 나오게 해줘.

[디자인]

- 단순한 사각형이나 원만 배치하지 말고
  실제 웹 게임처럼 시각적으로 보기 좋게 만들어줘.
- 건물, 도로, 자동차, 사람, 간판 등 각 요소가
  한눈에 구분되도록 만들어줘.
- 전체 화면의 완성도를 높여줘.

[구현 조건]

- 웹 브라우저에서 바로 실행할 수 있도록 만들어줘.
- 필요한 HTML, CSS, JavaScript를 모두 작성해줘.
- 별도의 복잡한 설치 없이 실행할 수 있게 만들어줘.
- 요청한 기능이 실제로 작동하도록 구현해줘.


==================================================
4. 결과 비교 체크리스트
==================================================

각 항목을 1~5점으로 평가해보세요.

1. 요구사항 반영
- 요청한 기능이 빠짐없이 구현되었는가?

2. 기능 완성도
- 캐릭터 이동이 정상적으로 작동하는가?
- 자동차와 보행자가 움직이는가?
- 충돌 판정이 정상 작동하는가?
- 회사 도착 시 성공 메시지가 나오는가?

3. 시각적 완성도
- 실제 게임처럼 보기 좋은가?
- 서울 강남이라는 배경이 느껴지는가?
- 한국어 간판과 도시 요소가 자연스럽게 표현되었는가?

4. 오류 여부
- 캐릭터가 건물을 통과하지 않는가?
- 충돌했는데 반응하지 않는 문제가 없는가?
- 화면이 깨지거나 동작하지 않는 부분이 없는가?

5. 첫 결과 완성도
- 추가 수정 없이 한 번의 프롬프트만으로
  어느 정도 완성된 결과가 나왔는가?

6. 작업 효율
- 결과 생성 속도는 어땠는가?
- 같은 결과를 만드는 데 불필요한 작업이 많지는 않았는가?

- [조건 B]가 발생하면 [동작 B]를 실행해줘.

[화면 구성]
- [필요한 화면 요소 1]
- [필요한 화면 요소 2]
- [필요한 화면 요소 3]

[디자인]
- 단순한 도형만 배치하지 말고
  실제 서비스 또는 게임처럼 시각적으로 보기 좋게 만들어줘.
- 사용자가 각 요소를 쉽게 구분할 수 있게 만들어줘.

[구현 조건]
- 웹 브라우저에서 바로 실행할 수 있게 만들어줘.
- 필요한 HTML, CSS, JavaScript를 모두 작성해줘.
- 요청한 기능이 실제로 정상 동작하도록 구현해줘.


==================================================
6. 실습 팁
==================================================

AI 모델을 공정하게 비교하려면 다음 조건을 맞추는 것이 좋습니다.

- 모든 모델에 동일한 프롬프트 사용
- 첫 번째 결과에서는 추가 수정 금지
- 동일한 평가 기준 사용
- 시각적 완성도와 기능 완성도를 따로 평가
- 가능하면 사용량과 비용도 함께 기록

핵심은
"어떤 AI가 무조건 최고인가?"
를 찾는 것이 아니라

"내 작업에서는 어떤 AI가 가장 효율적인가?"
를 직접 확인하는 것입니다.
