Claude로 15초 모션그래픽 만들기
배포용 프롬프트 모음

============================================================
1. 프로젝트 지침
============================================================

아래 내용을 Claude의 Project Instructions에 붙여넣어 사용하세요.

너는 15초 분량의 키네틱 타이포그래피 및 모션그래픽 제작을 지원한다.

다음 원칙을 따른다.

1. 기본 영상은 1920×1080, 30fps, 15초로 만든다.
   세로 영상이면 1080×1920으로 바꾼다.

2. 사용자가 준 문구와 정보만 우선 사용한다.
   확인되지 않은 숫자, 성과, 연혁은 임의로 만들지 않는다.

3. 바로 만들지 말고,
   먼저 어떤 문구가 언제 나오는지 간단한 표로 보여준다.

4. 글자가 화면 밖으로 잘리거나 서로 겹치지 않게 한다.
   배경과 글자는 잘 보이게 만든다.

5. 사용권을 확인하지 않은 음악, 이미지, 로고, 폰트는 함부로 사용하지 않는다.

6. 완성한 뒤 오탈자, 글자 잘림, 겹침, 가독성을 확인한다.
   움직이게 만든 요소가 실제로 움직이는지도 확인한다.

7. 현재 환경에서 원하는 파일을 만들 수 없다면,
   만들었다고 하지 말고 가능한 것과 불가능한 것을 정확하게 알려준다.


============================================================
2. 영상 제작 환경 확인 프롬프트
============================================================

먼저 현재 코드 실행 환경을 확인해 줘.

15초짜리 모션그래픽을 만들고
MP4 파일로 저장하는 데 필요한 도구를 사용할 수 있는지 확인해 줘.

한글이 깨지지 않게 표시할 수 있는 폰트와
영상에 소리를 넣을 수 있는지도 확인해 줘.

지금은 영상을 만들지 말고,
가능한지만 간단하게 알려 줘.

MP4로 만들기 어렵다면
지금 환경에서 가능한 다른 방법도 알려 줘.


============================================================
3. 영상 설계 프롬프트
============================================================

15초짜리 AI 채널 소개용 키네틱 타이포그래피 영상을 만들어 줘.

들어갈 문구는 다음과 같아.

“질문만 하는 AI에서”
“실제로 일하는 AI로”
“HappyAI”

스타일:
- 어두운 배경
- 굵고 읽기 쉬운 흰색 글자
- 포인트 컬러 1개
- 빠르고 깔끔한 테크 느낌

128 BPM을 기준으로 설계해 줘.

바로 제작하지 말고,
먼저 어떤 문구가 몇 초에 나오는지 표로 보여 줘.


============================================================
4. 실제 영상 제작 프롬프트
============================================================

좋아. 이 장면 구성으로 제작해 줘.

영상은 128 BPM의 일정한 리듬을 기준으로 움직이게 해 줘.

문구가 바뀌는 순간은 박자와 자연스럽게 맞춰 줘.
글자는 읽을 시간을 충분히 줘.

외부 음악은 사용하지 말고,
필요하면 간단한 128 BPM 리듬을 직접 만들어 줘.

현재 환경에서 가능하면
15초 MP4 파일까지 만들어 줘.

완료한 뒤에는
오탈자, 글자 잘림, 겹침,
글자가 잘 보이는지와
움직임이 실제로 정상 작동하는지도 확인해 줘.


============================================================
5. 수정 프롬프트 예시
============================================================

두 번째 장면의 글자를 지금보다 15% 정도 크게 해 줘.

마지막 HappyAI 아래에
“AI 기술 · 업무자동화” 문구를 작게 추가해 줘.

다른 장면의 문구, 색상, 움직임은 수정하지 마.

수정 후 결과를 다시 확인해 줘.


============================================================
6. 수정할 때 사용하는 기본 공식
============================================================

수정할 때는 아래 세 가지를 정확하게 말하면 됩니다.

1. 어느 장면을
2. 무엇을
3. 어떻게 바꿀지

예시:

“두 번째 장면의 제목을 15% 크게 해 줘.
등장 속도는 조금 늦춰 줘.
다른 장면은 수정하지 마.”


============================================================
7. 활용 팁
============================================================

- 반복해서 사용하는 규칙은 Project Instructions에 저장합니다.
- 영상마다 바뀌는 문구, 색상, 분위기는 채팅에서 입력합니다.
- 바로 제작하기보다 먼저 장면 구성을 확인합니다.
- 결과가 나오면 반드시 처음부터 끝까지 재생해 봅니다.
- 글자 잘림, 겹침, 오탈자, 가독성, 실제 움직임을 확인합니다.
- 외부 음악, 이미지, 폰트, 로고는 사용권을 확인합니다.
- 사용자 수, 순위, 성과 등 숫자는 근거 없이 만들지 않습니다.
- 현재 실행 환경에서 MP4 생성이 어렵다면 가능한 대안을 먼저 확인합니다.
