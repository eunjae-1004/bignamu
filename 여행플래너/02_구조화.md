# 구조화: 맞춤 여행코스 플래너

> 01_마스터컨텍스트.md를 단계·규칙·산출물 단위로 나눈 설계표입니다. 이 표가 03_프로젝트지침.md의 뼈대가 됩니다.

## 1. 전체 흐름

```
[1 지역] → [2 인원] → [3 관계] → [4 기간] → [5 예산] → [6 테마]
                                                          │
                                                          ▼
                                            [엑셀 데이터 필터링]
                                                          │
                                                          ▼
                                     ┌──▶ [일자별 초안 표] ──▶ <승인?>
                                     │                          │
                                     └──── 아니오(조건 수정) ◀──┤
                                                                │ 예
                                                    ┌───────────┴───────────┐
                                                    ▼                       ▼
                                             [코스 이미지 PNG]       [엑셀 견적서]
```

## 2. 선택 흐름 구조표

| 단계 | 질문 | 선택지 출처 | 입력 규칙 | 통과 조건 |
| --- | --- | --- | --- | --- |
| 1. 지역 | 어디로 가시나요? | 지역 시트 지역명 | 복수, 최대 3곳 | 1곳 이상 선택 |
| 2. 인원 | 성인·아동 몇 명인가요? | 직접 입력 | 숫자, 성인 1명 이상 | 합계 확인 |
| 3. 관계 | 어떤 사이인가요? | 고정 4개 | 단일 선택 | 1개 선택 |
| 4. 기간 | 며칠, 언제 출발하나요? | 직접 입력 | N박 N+1일, 출발일 | 성수기 여부 판정 |
| 5. 예산 | 예산은 얼마인가요? | 범위 선택지 또는 직접 입력 | 총액·1인 중 표기 | 금액 확인 |
| 6. 테마 | 어떤 여행을 원하나요? | 명소 테마태그 | 복수, 최대 2개 | 1개 이상 선택 |

공통 규칙: 한 번에 한 단계만 묻고, 단계 끝에 선택 요약 한 줄, '이전' 입력 시 직전 단계로 복귀.

## 3. 코스 생성 규칙

| 규칙 | 근거 시트 |
| --- | --- |
| 지역·테마태그·추천대상이 모두 맞는 항목만 사용 | 명소·숙소·식당 |
| 하루 이동+관람 합계 8시간 이내 | 명소·교통·견적기준 |
| 다중 지역은 교통 경로가 있는 순서로 배치 | 교통 |
| 방문일이 휴무일이면 제외 | 명소 |
| 아동은 아동 입장료 적용 | 명소 |
| 객실 수 = 인원 ÷ 객실 기준인원 (올림), 성수기면 할증 | 숙소·견적기준 |
| 렌터카 이용 시 대수 = 인원 ÷ 탑승 인원(올림), 비용 = 대수 × 일수 × 1일 요금 | 교통·견적기준 |
| 예산 초과 시 초과액 + 대안 2개 제시 후 확인 | 견적기준 |
| 조건에 맞는 항목이 부족하면 조건 완화안을 질문 | 전체 |

## 4. 견적 수량 규칙

| 구분 | 수량 계산 |
| --- | --- |
| 숙소 | 객실 수 × 박수 |
| 명소 | 성인·아동 각각 인원 수 (요금이 다르면 행을 나눔) |
| 식당 | 인원 수 × 식사 횟수 |
| 교통(버스) | 인원 수 × 구간 수 |
| 교통(렌터카) | 대수 × 일수 |
| 예비비 | 소계 × 예비비율 |

## 5. 산출물 규격

| 산출물 | 규격 |
| --- | --- |
| 초안 | 채팅 표: 일자, 시간대, 장소, 이동수단, 예상비용 |
| 코스 이미지 | PNG 1장: 제목, 일자별 동선, 이동수단, 총 예상비용 |
| 견적서 | 견적서양식 시트 구조, 금액은 수식 계산, 파일명 `견적서_지역_출발일.xlsx` |
| 채팅 요약 | 핵심 3줄 |

## 6. 테스트 시나리오

| 시나리오 | 입력 조건 | 확인할 점 |
| --- | --- | --- |
| A. 기본 | 가족 성인2·아동2, 강릉+속초, 2박3일, 자연 | 지역 순서, 아동 요금, 객실 수 |
| B. 예산 부족 | 연인 2명, 1박2일, 맛집, 낮은 예산 | 초과액 안내 + 대안 2개 |
| C. 데이터 부족 | 친구 6명, 경주+전주+여수, 휴무일 겹치는 날짜 | 휴무 제외, 경로 없는 구간 '데이터 없음', 임의 생성 여부 |
