# 맞춤형 여행코스 생성 프로젝트 만들기 — 초보 학습자 실습 예시

Oct 30, 2026 · @eunjae

## 과제 개요

학습자는 Claude와 대화만으로 '맞춤 여행코스 플래너' 프로젝트를 완성한다. 이 프로젝트는 6단계 선택을 받아 **기초 데이터 엑셀**에서 장소·숙소·식당을 골라 **코스 이미지**와 **엑셀 견적서**를 만든다.

| 단계 | 학습자가 하는 일 | 산출물 |
| --- | --- | --- |
| 0. 준비 | 기초 데이터 엑셀 구조 확인 | 여행기초데이터.xlsx |
| 1. 요구 발굴 | Claude에게 인터뷰를 요청해 질문에 답함 | 대화 기록 |
| 2. 마스터 컨텍스트 | 대화 결과를 한 장으로 정리시킴 | 마스터 컨텍스트 |
| 3. 구조화 | 선택 흐름·규칙·입출력을 표로 정리시킴 | 구조 설계표 |
| 4. 프로젝트 생성 | 이름·설명·지침·지식 파일 등록 | Claude 프로젝트 |
| 5. 테스트·개선 | 시나리오로 돌려 보고 지침 수정 | 완성 프로젝트 |

'이미지 생성'은 사진형 그림이 아니라 일자별 동선을 그린 **인포그래픽(PNG/HTML)** 으로 설계한다. Claude는 코드로 그림·엑셀 파일을 만드는 방식이므로, 학습 환경에서 파일 생성(코드 실행) 기능이 켜져 있는지 **확인 필요**.

## 0단계 준비: 기초 데이터 엑셀

프로젝트의 근거는 엑셀 한 파일(여행기초데이터.xlsx)이다. 시트마다 '지역코드'로 연결해 두면 Claude가 선택 지역만 정확히 걸러낸다. 아래 값은 **실습용 가상 예시**이며 실제 운영 시 자사 데이터로 교체한다.

| 시트 | 필수 컬럼 | 쓰이는 단계 |
| --- | --- | --- |
| 지역 | 지역코드, 지역명, 권역 | 1단계 지역 선택지 |
| 명소 | 명소ID, 지역코드, 명소명, 테마태그, 추천대상, 소요시간(시간), 1인 입장료(원), 휴무일 | 코스 구성 |
| 숙소 | 숙소ID, 지역코드, 숙소명, 유형, 객실 기준인원, 1박 요금(원), 성수기 할증률(%) | 코스·견적 |
| 식당 | 식당ID, 지역코드, 식당명, 메뉴유형, 1인 평균단가(원), 추천대상 | 코스·견적 |
| 교통 | 출발지역, 도착지역, 수단, 소요시간(시간), 1인 요금(원) | 다중 지역 동선·견적 |
| 견적기준 | 항목, 기준값 (예비비율, 성수기 기간 등) | 견적 계산 |
| 견적서양식 | 상단 정보, 항목·단가·수량·금액, 소계·예비비·합계 칸 | 최종 견적서 |

'명소' 시트 예시 (가상):

```csv
명소ID,지역코드,명소명,테마태그,추천대상,소요시간(시간),1인 입장료(원),휴무일
S001,GN,강릉 해변 A,자연|휴식,가족|연인,2,0,없음
S002,GN,강릉 전통마을 B,역사,가족|단체,1.5,3000,월
S003,SC,속초 시장 C,맛집|쇼핑,친구|가족,1.5,0,없음
S004,SC,속초 전망대 D,자연|액티비티,친구|연인,2,12000,화
```

데이터 작성 원칙 세 가지만 학습자에게 강조한다.

1. 태그는 정해진 단어만 쓴다 (테마: 자연·역사·맛집·액티비티·휴식·쇼핑 / 대상: 가족·친구·연인·단체).
2. 여러 값은 `|`로 구분하고, 금액은 숫자만 넣는다 (단위는 헤더에).
3. 빈칸은 '없음'으로 채운다. 빈칸이 있으면 Claude가 임의로 추정할 수 있다.

## 1단계 대화형 요구 발굴

초보자는 지침을 직접 쓰지 않는다. **Claude에게 인터뷰어 역할을 맡기고 질문에 답만** 하면 요구사항이 모인다. 핵심은 첫 프롬프트에 '한 번에 하나씩 질문'을 넣는 것이다.

**학습자 (시작 프롬프트)**

> 여행 코스를 자동으로 만들어 주는 Claude 프로젝트를 만들고 싶어. 나는 초보라서 지침을 어떻게 써야 할지 몰라. 네가 기획자처럼 나를 인터뷰해 줘. 질문은 한 번에 하나씩, 가능하면 선택지를 붙여서 해 줘. 다 끝나면 내가 '정리해 줘'라고 할게. 기초 데이터 엑셀을 첨부할게.

**Claude**

> 좋습니다. 첨부하신 엑셀에 지역·명소·숙소·식당·교통·견적기준·견적서양식 7개 시트가 있네요. 첫 질문입니다. 이 프로젝트는 누가 쓰나요? ① 여행사 상담 직원 ② 여행객 본인 ③ 둘 다

**학습자**: ① 상담 직원이 고객과 통화하면서 써.

**Claude**

> 고객 정보를 단계별로 받아야겠네요. 받을 항목으로 지역(복수), 인원수, 구성원 관계, 기간, 예산, 테마를 생각하고 있습니다. 빠지거나 바꿀 항목이 있나요?

**학습자**: 인원수는 성인/아동 나눠 줘. 아동은 입장료가 다르거든.

**Claude**

> 반영하겠습니다. 다만 현재 명소 시트에는 아동 요금 컬럼이 없습니다. ① 시트에 '아동 입장료' 컬럼 추가 ② 성인 요금의 일정 비율 적용 중 어느 쪽인가요?

**학습자**: ①로 할게. 데이터에 추가할게.

**Claude**

> 예산을 초과하면 어떻게 할까요? ① 초과액을 알려 주고 대안 제시 ② 예산 안에서만 자동 구성

**학습자**: ①. 대안은 두 개만.

**Claude**

> 최종 산출물을 확인하겠습니다. 코스 이미지는 일자별 동선을 그린 인포그래픽, 견적서는 '견적서양식' 시트 그대로 채운 엑셀이 맞나요? 산출물을 만들기 전 초안 확인 단계를 둘까요?

**학습자**: 맞아. 초안 표로 먼저 보여 주고 내가 OK하면 만들어.

**학습자 (마무리 프롬프트)**

> 정리해 줘. 지금까지 결정된 것과 아직 안 정한 것을 나눠서 보여 줘.

인터뷰에서 학습자가 놓치기 쉬운 질문은 강사가 미리 짚어 준다: 데이터에 없는 항목 처리, 예산 초과 처리, 산출물 생성 전 확인 여부, '이전 단계로' 되돌리기.

## 2단계 마스터 컨텍스트 작성

마스터 컨텍스트는 '이 프로젝트가 무엇이고 무엇을 근거로 무엇을 내놓는가'를 한 장에 담은 기준 문서다. 이후 구조화·지침 작성은 모두 이 문서를 기준으로 한다.

**학습자 프롬프트**

> 인터뷰 내용을 마스터 컨텍스트로 정리해 줘. 항목은 목적, 사용자, 입력, 데이터, 처리 규칙, 출력, 금지 사항, 미정 사항으로 해 줘. 내가 말하지 않은 내용은 넣지 말고 '미정'으로 표시해 줘.

**Claude가 만든 마스터 컨텍스트 (예시)**

```markdown
# 마스터 컨텍스트: 맞춤 여행코스 플래너

## 목적
상담 직원이 고객 조건을 단계별로 입력하면, 기초 데이터에 근거한 여행 코스와 견적서를 즉시 만든다.

## 사용자
여행사 상담 직원 (고객 통화 중 사용)

## 입력 (6단계, 순서 고정)
1. 여행 지역: 복수 선택
2. 인원수: 성인 / 아동 구분
3. 구성원 관계: 가족 / 친구 / 연인 / 단체
4. 기간: 박·일, 출발일
5. 예산: 총액 또는 1인 기준
6. 테마: 복수 선택

## 데이터
여행기초데이터.xlsx (지역·명소·숙소·식당·교통·견적기준·견적서양식)
명소 시트에 '아동 입장료' 컬럼 추가 예정

## 처리 규칙
- 선택 지역 + 테마태그 + 추천대상이 맞는 항목만 사용
- 예산 초과 시 초과액 안내 + 대안 2개
- 산출물 생성 전 일자별 초안 표로 확인받기

## 출력
1. 코스 이미지: 일자별 동선 인포그래픽
2. 견적서: 견적서양식 시트 구조의 엑셀 파일

## 금지 사항
- 데이터에 없는 장소·가격 생성 금지

## 미정 사항
- 선택 가능한 지역 수 상한
- 하루 최대 일정 시간
- 견적서 파일명 규칙
```

강사는 '미정 사항'을 학습자가 직접 결정하게 한다. 예: "지역은 최대 3곳, 하루 일정은 8시간 이내로 해 줘." 이 결정이 다음 단계 구조화의 규칙이 된다.

## 3단계 구조화

구조화는 마스터 컨텍스트를 '단계마다 무엇을 묻고, 어떤 데이터로, 무엇을 검사하는가'의 표로 바꾸는 작업이다. 이 표가 그대로 지침의 뼈대가 된다.

&#91;embedded content: 프로젝트 진행 흐름 · 6단계 선택, 1회 승인, 산출물 2종\]

승인 전에는 파일을 만들지 않고, 수정 요청이 오면 초안 단계로 돌아간다.

**학습자 프롬프트**

> 마스터 컨텍스트를 바탕으로 6단계 선택 흐름을 표로 구조화해 줘. 열은 단계, 질문, 선택지 출처, 입력 규칙, 다음 단계로 넘어가는 조건으로 해 줘. 그다음 코스 생성 규칙과 산출물 규격도 따로 표로 정리해 줘.

**선택 흐름 구조표 (예시)**

| 단계 | 질문 | 선택지 출처 | 입력 규칙 | 통과 조건 |
| --- | --- | --- | --- | --- |
| 1. 지역 | 어디로 가시나요? | 지역 시트 지역명 | 복수, 최대 3곳 | 1곳 이상 선택 |
| 2. 인원 | 성인·아동 몇 명인가요? | 직접 입력 | 숫자, 성인 1명 이상 | 합계 확인 |
| 3. 관계 | 어떤 사이인가요? | 고정 4개 | 단일 선택 | 1개 선택 |
| 4. 기간 | 며칠, 언제 출발하나요? | 직접 입력 | N박 N+1일, 출발일 | 성수기 여부 판정 |
| 5. 예산 | 예산은 얼마인가요? | 범위 선택지 또는 직접 입력 | 총액·1인 중 표기 | 금액 확인 |
| 6. 테마 | 어떤 여행을 원하나요? | 명소 테마태그 | 복수, 최대 2개 | 1개 이상 선택 |

**코스 생성 규칙**

| 규칙 | 근거 시트 |
| --- | --- |
| 지역·테마태그·추천대상이 모두 맞는 항목만 사용 | 명소·숙소·식당 |
| 하루 이동+관람 합계 8시간 이내 (학습자 결정값) | 명소·교통 |
| 다중 지역은 교통 경로가 있는 순서로 배치 | 교통 |
| 방문일이 휴무일이면 제외 | 명소 |
| 객실 수 = 인원 ÷ 기준인원 (올림), 성수기면 할증 | 숙소·견적기준 |
| 예산 초과 시 초과액 + 대안 2개 제시 후 확인 | 견적기준 |

**산출물 규격**

| 산출물 | 규격 |
| --- | --- |
| 초안 | 채팅 표: 일자, 시간대, 장소, 이동수단, 예상비용 |
| 코스 이미지 | PNG 1장: 제목, 일자별 동선, 이동수단, 총 예상비용 |
| 견적서 | 견적서양식 시트 구조, 금액은 수식 계산, 파일명 견적서\_지역\_출발일.xlsx |

## 4단계 프로젝트 생성

마스터 컨텍스트와 구조표를 Claude에게 주고 '프로젝트 지침'으로 변환시킨 뒤, 프로젝트에 이름·설명·지침·지식 파일 네 가지를 등록한다.

**학습자 프롬프트**

> 마스터 컨텍스트와 구조표를 Claude 프로젝트 지침으로 바꿔 줘. 역할, 진행 방식, 코스 생성 규칙, 확인 절차, 산출물, 금지 사항 순서로. 프로젝트 이름과 한 줄 설명도 같이 제안해 줘.

| 등록 항목 | 입력 내용 (예시) |
| --- | --- |
| 이름 | 맞춤 여행코스 플래너 |
| 설명 | 6단계 선택으로 기초 데이터 기반 여행 코스 이미지와 엑셀 견적서를 만든다 |
| 지침 | 아래 전문 |
| 지식 파일 | 여행기초데이터.xlsx (견적서양식 시트 포함) |

**지침 전문 (예시)**

```markdown
# 역할
너는 여행사 상담 직원을 돕는 '맞춤 여행코스 플래너'다.
프로젝트 지식의 '여행기초데이터.xlsx'만 근거로 코스와 견적을 만든다.

# 진행 방식
- 대화가 시작되면 1단계부터 시작한다. 한 번에 한 단계만 묻는다.
- 매 단계 번호 선택지를 준다. 선택지는 데이터 시트에서 읽어 온다.
- 각 단계 끝에 지금까지의 선택을 한 줄로 요약한다.
- 사용자가 '이전'이라고 하면 직전 단계로 돌아간다.

1단계 여행 지역: 지역 시트의 지역명, 복수 선택(최대 3곳)
2단계 인원수: 성인/아동 각각 숫자 (성인 1명 이상)
3단계 구성원 관계: 가족/친구/연인/단체 중 1개
4단계 기간: N박 N+1일과 출발일 (견적기준 시트로 성수기 판정)

# 코스 생성 규칙
- 지역·테마태그·추천대상이 모두 맞는 명소·숙소·식당만 쓴다.
- 하루 이동+관람 합계는 8시간 이내로 한다.
- 다중 지역은 교통 시트에 경로가 있는 순서로 배치한다.
- 방문일이 휴무일인 명소는 제외한다.
- 객실 수는 인원 ÷ 객실 기준인원(올림), 성수기면 할증률을 적용한다.
- 예산을 넘으면 초과액과 대안 2개를 제시하고 선택을 받는다.

# 확인 절차
```

## 5단계 테스트·개선

프로젝트는 일부러 까다로운 조건으로 돌려 봐야 지침의 빈틈이 보인다. 시나리오 3개를 돌리고, 틀린 결과는 '지침 수정 프롬프트'로 고친다.

| 시나리오 | 입력 조건 | 확인할 점 |
| --- | --- | --- |
| A. 기본 | 가족 성인2·아동2, 강릉+속초, 2박3일, 자연 | 지역 순서, 아동 요금 반영, 객실 수 |
| B. 예산 부족 | 연인 2명, 1박2일, 맛집, 예산을 낮게 입력 | 초과액 안내 + 대안 2개 |
| C. 데이터 부족 | 친구 6명, 3개 지역, 휴무일이 겹치는 날짜 | 휴무 명소 제외, '데이터 없음' 표시, 임의 생성 여부 |

**완성 체크리스트**

- [ ] 한 번에 한 단계만 묻고 선택지를 데이터에서 가져온다
- [ ] '이전' 입력 시 직전 단계로 돌아간다
- [ ] 초안 표를 먼저 보여 주고 승인 후 산출물을 만든다
- [ ] 코스의 모든 장소·가격이 엑셀에 실제로 있다
- [ ] 견적서 금액이 수식으로 계산되고 합계가 맞다
- [ ] 코스 이미지에 일자·장소·이동수단·총비용이 모두 있다

**흔한 오류와 수정 프롬프트**

| 증상 | 수정 프롬프트 예시 |
| --- | --- |
| 6단계를 한 번에 다 물어봄 | 지침의 진행 방식에 '한 단계의 답을 받기 전에는 다음 질문을 하지 않는다'를 추가해 줘 |
| 엑셀에 없는 맛집을 추천함 | 금지 사항에 '추천 전 해당 시트에 있는지 확인하고, 없으면 쓰지 않는다'를 추가해 줘 |
| 견적서 금액이 숫자로만 박혀 있음 | 견적서 규칙에 '단가×수량, 소계, 합계는 엑셀 수식으로 넣는다'를 명시해 줘 |
| 초안 확인 없이 파일부터 만듦 | 확인 절차를 산출물 규칙보다 위로 올리고 '승인 전 파일 생성 금지'를 넣어 줘 |

수정할 때는 지침 전체를 다시 쓰게 하지 말고 "이 줄만 바꿔 줘"로 요청하게 한다. 무엇을 고쳤는지 학습자가 추적할 수 있다.
