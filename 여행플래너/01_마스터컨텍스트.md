# 마스터 컨텍스트: 맞춤 여행코스 플래너

> 이 문서는 프로젝트의 기준 문서입니다. 구조화(02)와 프로젝트 지침(03)은 모두 이 문서를 근거로 작성합니다.

## 1. 목적
상담 직원이 고객 조건을 6단계로 입력하면, 기초 데이터 엑셀에 근거한 여행 코스와 견적서를 바로 만든다.

## 2. 사용자
- 여행사 상담 직원 (고객과 통화하면서 사용)

## 3. 입력 (6단계, 순서 고정)
| 단계 | 항목 | 입력 방식 |
| --- | --- | --- |
| 1 | 여행 지역 | 복수 선택, 최대 3곳 |
| 2 | 인원수 | 성인 / 아동 구분 (성인 1명 이상) |
| 3 | 구성원 관계 | 가족 / 친구 / 연인 / 단체 중 1개 |
| 4 | 기간 | N박 N+1일, 출발일 |
| 5 | 예산 | 총액 또는 1인 기준 |
| 6 | 테마 | 자연 / 역사 / 맛집 / 액티비티 / 휴식 / 쇼핑 중 최대 2개 |

## 4. 데이터
파일: `여행기초데이터.xlsx` (실습용 가상 데이터)

| 시트 | 내용 | 규모 |
| --- | --- | --- |
| 안내 | 데이터 작성 규칙 | - |
| 지역 | 지역코드, 지역명, 권역 | 8곳 |
| 명소 | 테마태그, 추천대상, 소요시간, 성인·아동 입장료, 휴무일 | 48건 |
| 숙소 | 유형, 객실 기준인원, 1박 요금, 성수기 할증률 | 24건 |
| 식당 | 메뉴유형, 테마태그, 1인 평균단가 | 32건 |
| 교통 | 출발·도착지역, 수단, 소요시간, 1인 요금 | 16구간 |
| 견적기준 | 예비비율, 렌터카 요금, 성수기 기간, 하루 최대 일정 등 | 9항목 |
| 견적서양식 | 참조ID·수량 입력 시 항목명·단가·금액 자동 계산 | - |

- 시트 연결 키: 지역코드 (명소·숙소·식당), 출발지역/도착지역 (교통)
- 여러 값은 `|`로 구분, 빈칸은 '없음'

## 5. 처리 규칙
- 선택 지역 + 테마태그 + 추천대상이 모두 맞는 항목만 사용
- 하루 이동+관람 합계는 견적기준의 '하루 최대 일정'(8시간) 이내
- 다중 지역은 교통 시트에 경로가 있는 순서로 배치
- 방문일이 휴무일인 명소는 제외
- 아동은 명소의 '아동 입장료' 적용
- 성수기(견적기준의 시작~종료일) 출발이면 숙소 할증률 적용
- 예산 초과 시 초과액 안내 + 대안 2개 제시
- 산출물 생성 전 일자별 초안 표로 확인받기

## 6. 출력
1. 초안: 채팅 표 (일자, 시간대, 장소, 이동수단, 예상비용)
2. 코스 이미지: 일자별 동선 인포그래픽 PNG 1장
3. 견적서: 견적서양식 시트 구조의 엑셀 파일 (`견적서_지역_출발일.xlsx`)

## 7. 금지 사항
- 데이터에 없는 장소·가격·운영시간 생성 금지 → '데이터 없음' 표시
- 승인 전 파일 생성 금지

## 8. 확인 필요 사항
- 실습 계정의 파일 생성(코드 실행) 기능 사용 가능 여부
- 실제 운영 시 가격 데이터 출처와 갱신 주기
